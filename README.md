# Оно тебе надо

Репозиторий проекта: https://github.com/shmaaaaa1/ono-tebe-nado

Одностраничный сайт аукциона вещей, в которые никто не верил. Статическая вёрстка на HTML и CSS.

## Структура проекта

- `index.html` — главная страница.
- `styles/` — стили: `global.css` (сброс и базовые правила), `style.css` (стили страницы).
- `fonts/` — шрифт Raleway в форматах WOFF2 и WOFF и файл `fonts.css` с объявлениями `@font-face`.
- `images/` — изображения и логотипы в формате SVG.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

## Поддерживаемые браузеры

Firefox, Google Chrome, Yandex Browser.
